# Backend Phase 11 - Laporan Distribusi

Phase 11 menambahkan modul laporan distribusi untuk admin dan kepala SPPG.

## Ruang lingkup

- Halaman laporan distribusi.
- Filter laporan berdasarkan tanggal jadwal dan status distribusi.
- Ringkasan jumlah distribusi per status.
- Ringkasan total tujuan, tujuan terkirim, porsi rencana, porsi terkirim, dan jarak rute.
- Tabel distribusi dengan petugas, depot, status, progres tujuan, progres porsi, dan jarak.
- Export CSV laporan distribusi sesuai filter.

## Akses

- Admin dapat melihat dan export laporan.
- Kepala SPPG dapat melihat dan export laporan.
- Petugas tidak diberi akses laporan global.

## Catatan batasan

Phase ini memakai export CSV sederhana. Export PDF atau chart visual dapat ditambahkan pada phase lanjutan.
